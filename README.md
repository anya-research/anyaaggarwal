# Anya Aggarwal

Portfolio website of Anya Aggarwal — AI/ML researcher and student researcher at [Under Research Labs](https://github.com/Under-Research-Labs), focusing on foundation-model systems, agentic reasoning, and tool-augmented inference.

## 🚀 Stack

- **Framework:** SvelteKit 2 & Svelte 5
- **Styling:** Tailwind CSS 4 & DaisyUI
- **Language:** TypeScript
- **Deployment:** GitHub Pages (`@sveltejs/adapter-static`)

## 🛠️ Development

Install dependencies:

```sh
pnpm install
```

Start the development server:

```sh
pnpm run dev
```

Build static output:

```sh
pnpm run build
```

Run type checks:

```sh
pnpm run check
```
